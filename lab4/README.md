## Про что сайт

Это лендинг вымышленной веб-студии **«Пиксель»**. Студия делает сайты, которые не просто «лежат» на экране, а отвечают на курсор: свет, частицы, живые карточки и смена стиля.

Сайт рассказывает три вещи:

1. **Кто мы.** Пиксель — маленькая студия: дизайн, код и движение в одной комнате, без конвейера и шаблонной сетки.
2. **Что умеем.** Лендинг, магазин, портфолио, медиа. Сначала выбирается форма сайта, потом характер — аниме, fashion или творческое портфолио.
3. **Как начать.** Короткое сообщение важнее длинного брифа: имя, контакт и задача уходят «сигналом» студии.

Идея страницы: посетитель не читает сухой каталог услуг, а сразу видит, как может выглядеть живой сайт.

## Что внутри

Одна страница с якорной навигацией (вместо отдельных html-файлов):

| Блок | Якорь | О чём |
|------|--------|--------|
| Шапка | — | Логотип «Пиксель», меню: Главная, Услуги, О нас, Контакты |
| О сайте | `#about` | Живой мини-браузер: наведи — макет «дышит». Рядом карточки: характер, движение, точность |
| Услуги | `#services` | Виды сайтов: лендинг, магазин, портфолио, медиа |
| Дизайны | `#designs` | Три стиля. Наведи — карточка оживает. Нажми — **весь сайт** перекрашивается в этот мир |
| О нас | `#us` | Роли студии (дизайн / код / движение) и путь: слушаем → собираем → запускаем |
| Контакты | `#contacts` | Чат-форма заявки, почта `hello@pixel.studio`, Telegram |

### Три мира (по клику на карточку)

- **Аниме** — красный акцент, японские подписи, вырезанные персонажи за карточками
- **Fashion** — фиолетовый неон, fashion-модель, журнальный ритм
- **Folio** — оранжевый акцент, портрет в наушниках по центру, творческое портфолио

## Как сделано

- HTML5 + CSS3 + JavaScript (без фреймворков)
- Стеклянные карточки, частицы на canvas, свой курсор на десктопе
- Смена темы через `body[data-theme="anime|fashion|folio"]`
- Шрифты: Manrope, Unbounded, Noto Sans JP, Oswald
- Картинки лежат локально в `src/img/` — страница открывается и с GitHub Pages, и с диска
