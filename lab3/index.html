Работа с анимацией · CSS transitions и @keyframes

1. CSS Transition (при наведении)

Свойство transition плавно меняет фон и масштаб кнопки при hover.

Карточка с transition

transition: background-color 0.4s ease, transform 0.4s ease;

2. @keyframes: круг → прямоугольник → квадрат

Розовый круг превращается в синий квадрат через промежуточный фиолетовый прямоугольник (идея из учебника).

animation-name: circle-to-square; animation-duration: 5s; animation-iteration-count: infinite;

3. Свойства анимации — демо-карточки

animation-name

Имя анимации, связанное с блоком @keyframes. Здесь: pulse.

animation-duration

Длительность одного цикла. Слева 1s, справа (этот блок) 3s — медленнее.

animation-iteration-count

Число повторов. Значение infinite — бесконечно.

animation-direction

alternate — туда и обратно; reverse — в обратном порядке.

animation-timing-function

Кривая скорости: ease, linear, ease-in-out, steps().

animation-delay

Задержка перед стартом. Здесь 1.5s — анимация начинается позже.

animation-fill-mode

forwards сохраняет стили последнего кадра после окончания анимации.

animation (сокращение)

Краткая запись: name duration timing delay iteration direction fill-mode.

Кратко для контрольных вопросов

  • animation-name — имя @keyframes, применяемое к элементу.
  • animation-duration — длительность одного цикла (s / ms).
  • animation-iteration-count — сколько раз проиграть (число или infinite).
  • animation-direction — направление: normal, reverse, alternate, alternate-reverse.
  • animation-timing-function — скорость изменения во времени.
  • animation-delay — пауза перед первым запуском.
  • animation-fill-mode — стили до/после анимации (none, forwards, backwards, both).
