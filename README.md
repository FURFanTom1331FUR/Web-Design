# Легенды русской поэзии

Лабораторная работа № 1 по дисциплине **Web-дизайн**.

Одностраничный сайт на чистом HTML и CSS: шапка и подвал с якорями, секции поэтов (Есенин, Пушкин, Маяковский, Лермонтов).

## Структура

- `index.html` — разметка
- `style/style.css` — стили
- `src/` — логотип и портреты

## Открыть локально

Открой `index.html` в браузере.
